### 💜🎌 ANIME HUB – DESKTOP & MOBILE WEBPAGE DESIGN 🌸✨

🌟 **Anime Hub** is an anime community platform created for anime lovers to explore their favourite anime, join exciting communities, discover trending content, and connect with fellow fans. The website features a beautiful purple and lavender theme, attractive anime illustrations, stylish typography, and a user-friendly interface. 💜🦋

### 💻🖥️ Desktop Screen Features



<img width="1440" height="1024" alt="Desktop " src="https://github.com/user-attachments/assets/3e7ecaa2-9e29-49b1-a7b5-7421d82e4aec" />




🟣 **1. Sidebar Navigation:** Provides easy access to Home 🏠, Channels ▦, Groups 👥, and Discover 🔎.

🔍 **2. Search Bar:** Helps users quickly search for anime series, channels, and community members.

👤 **3. Welcome Section:** Displays a personalized greeting, anime profile picture, and notification bell 🔔.

🏯 **4. Hero Banner:** Features a stunning Japanese-inspired anime landscape with the message *“Explore. Watch. Discuss.”* 🌸🌄

💬 **5. Popular Channels:** Showcases Anime News 📰, Manga Drops 📚, and Fan Art Hub 🎨, along with their member counts.

🔥 **6. Trending Anime:** Displays attractive anime thumbnails to highlight popular and trending content.

### 📱🌈 Mobile Screen Features

📲 **1. Responsive Layout:** Adapts the webpage to mobile screens for a smooth browsing experience.

👧 **2. Compact Profile Header:** Displays the user's anime avatar, welcome message, and notification icon.

🔎 **3. Mobile Search Bar:** Allows users to find anime, channels, and other members easily.

🎯 **4. Category Navigation:** Includes Channels 💜, Groups 🌸, and Discover ✨ buttons for quick access.

🖼️ **5. Popular Channel List:** Presents community names, anime avatars, and member counts in a clean vertical layout.

➕ **6. Bottom Navigation Bar:** Provides quick access to Home 🏠, Channels ▦, Create ➕, Messages 💌, and Profile 👤.

### 🎨🦄 Technologies and Design Highlights

💜 **Colour Theme:** Deep purple, soft lavender, white, and pastel pink.

🖋️ **Typography:** Decorative headings combined with clear, readable text.

🖼️ **Visual Elements:** Anime avatars, colourful banners, illustrated thumbnails, and rounded cards.

📐 **Responsive Design:** Organizes content to suit both desktop and mobile screen sizes.

✨ **User Experience:** Simple navigation, attractive visuals, and easy access to anime communities.
